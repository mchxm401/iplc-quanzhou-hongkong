## 泉港 IPLC 是什么：从泉州电信机房拉到香港的物理专线

IPLC 的全称是 International Private Leased Circuit，也就是国际私有租用线路。按维基百科的定义，它是连接两个地区的对称电信线路，和普通上网线路最大的区别在于：数据从泉州电信机房出来后走的是点对点的专用链路，不经过公网国际出口。这是它和普通 BGP 中转线路在原理上的核心差异。

MKCloud 是一家专注跨境网络的专线服务商，产品线覆盖广港、沪港、沪日、沪美和福建高防方向。泉港 IPLC 属于它的“福建-香港 高防IPLC专线”产品组，官方产品代号是 `qz-hk-ex`，定位是独享带宽专线 VPS。同组还有厦门 BGP 入口的厦港专线，两条都是独享款。

交付形态要说清楚：你买到的是一台 VPS，每台机器分配 1 个独立入口 IP 和 1 个独立出口 IP。你连入口 IP 操作服务器，跑在里面的程序自动从香港出口对外访问。它不是裸专线，不能拿来接你办公室的网线，也不能把出口当网站服务器用，这一点后面还会展开。

## 独享带宽和共享带宽，差价为什么有十倍

看泉港价格之前，得先弄明白独享和共享的区别，否则 4200 元这个数字会显得莫名其妙。

共享带宽产品（比如广港 IEPL 的流量计费套餐）给的是峰值带宽。MKCloud 广港共享入门档是 1 核 2GB、200M 峰值、每月 1TB 流量，月付 358 元。官方知识库明确写了：共享带宽是峰值，不保证持续跑满，而且流量按上下行双向统计，超额后会暂停，要买流量重置或补差价升级。

独享带宽产品给的是按配置确定的带宽。泉港 IPLC 的 200Mbps 是独享的，流量不限。代价就是价格：4200 元/月对 358 元/月，差了十几倍。

这笔账怎么算，取决于你的业务形态。如果你的场景是间歇性上传选品数据、每天几十 GB 的日常办公，共享峰值完全够用，多花的钱买不到对应的收益。但如果你要长时间持续传输——比如 TikTok 直播推流、大文件持续同步、多账号 ERP 甩货——峰值再高也解决不了持续速率问题，这时候独享带宽才真正派上用场。官方知识库的原话是：短时间上传可能更看重峰值，长时间传输更看重持续速率与额度。

## 100Gbps DDoS 高防和“无跨省 QoS”意味着什么

官方 Telegram 频道对泉港的宣传原话是：全天候无跨省跨网 QoS，无省份限制，含 100Gbps DDoS 高防。拆开看，QoS 这条说的是流量不经过跨省跨网环节，减少了被运营商限速策略影响的可能；高防这条对游戏、金融、大促期间的电商这类容易被打的业务是实打实的价值，毕竟独享出口 IP 一旦被打挂，损失的是整个店面的营业时间。

不过要把官方知识库的谨慎口径也如实转达：目前公开资料并没有给出可以独立核实的完整防护报告，防护对象、阈值、清洗范围和触发条件这些细节暂不公开。官方建议有明确防护需求的用户直接通过工单确认，而不是只看宣传里的数字。这个态度反而让“100Gbps”这个数字显得更可信一些——真正谈不了细节的高防，才需要一直喊口号。

## 常见问题

**200Mbps 独享能跑满吗？**

独享带宽的口径是按配置带宽交付，但官方知识库明确说不承诺任何时刻跑满，实际速度还受服务器性能、目标服务限速和协议影响。直播推流这类场景建议开通后先测持续速率，再决定要不要加档。

**泉港 IPLC 比 IEPL 慢吗？**

不能一概而论。广港 IEPL 的端内延迟官方标 1~2ms，是同方向最低的；泉港的延迟口径在不同来源间有分歧（见前文）。但“慢不慢”最终取决于业务：访问网页、盯后台，几十毫秒的差别感知有限；持续推流和传输，独享带宽的稳定性比端内延迟的十几毫秒更重要。

**4200 元/月贵吗？**

看跟谁比。跟共享套餐比，它贵一个量级；但跨境专线市场的参考价是每 Mbps 每月 300~800 元（第三方 SD-WAN 价格指南口径），按这个口径 200Mbps 独享要 6 万起步。MKCloud 泉港 4200 元拿下 200M 独享加 100Gbps 防护，比同店广港独享 200M（约 5400 元）和厦港独享 200M（约 6000 元）都低，属于“贵但没贵得离谱”的位置。反过来说，如果你不需要独享和高防，就别为这两个属性付这笔钱。

**个人能用吗？**

需要中国身份实名，且官方明确限制用途为个人或企业正规用途，防止机场、回国等违规用法。如果你没有跨境业务需求，这个价位和门槛本来也不是为个人轻度使用准备的。

**支持退款吗？**

仅质量问题支持退款，需要提交具体延迟、速度数据证明，由官方审核；开通后不支持更换地域。下单前把配置选对，比事后扯皮省心得多。
